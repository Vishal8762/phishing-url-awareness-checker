# Phishing URL Awareness Checker

## Project Overview
A Python program that checks URL text for selected phishing warning signs.

## Features
- Detects @ symbol
- Checks URLs longer than 100 characters
- Detects IP addresses
- Checks multiple hostname segments
- Detects punycode hostnames
- Detects HTTP scheme

## Requirements
- Python 3.10 or newer
- No external packages required

## How to Run
Run this command:

py phishing_checker.py

## Testing
Five sample URLs were tested successfully.

## Improvements
- Added repeated URL checking.
- Added invalid URL handling.

## Limitations
This tool cannot guarantee that a website is safe.

## Ethical Use
The program does not open URLs. Use sample URLs only.
